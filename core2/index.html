OBJ 2.6
Malware Removal — 10-Step Process (In Order)

Steps 1–5

  • 1
    Investigate & verify malware symptoms — Odd errors, slow performance, security alerts, crashed apps. Research what you're dealing with
  • 2
    Quarantine infected systems — Disconnect from network immediately. Isolate removable media. Prevent spread. Do NOT try to backup or transfer files
  • 3
    Disable System Restore — Restore points can re-infect. Delete all restore points. Disable System Protection. No reason to save an infected config
  • 4
    Remediate infected systems — Provide a remedy, remove malicious files, quarantine files that can't be deleted. This is often difficult
  • 5
    Update anti-virus/anti-malware — Update signatures and engine. Manual updates are nearly pointless if malware prevents it — copy from another computer

Steps 6–10

  • 6
    Scan & removal techniques — Use Safe Mode (bare minimum OS) or WinPE / Pre-installation environment. May need to repair boot records/sectors
  • 7
    Reimage / reinstall if needed — Delete everything and reinstall. Only 100% guaranteed removal method. Reimage from known-good image (fastest). This is why docs are stored on network
  • 8
    Schedule scans and run updates — Set automated AV scans and signature updates. Task Scheduler. Enable OS updates
  • 9
    Enable System Protection — Re-enable System Restore. Create a new restore point. System is now clean
  • 10
    Educate the end user — One-on-one, posters, message boards, login messages, intranet pages. Ongoing security awareness
🔴 CRITICAL ORDER: Quarantine (step 2) ALWAYS comes before remediation (step 4). Disable System Restore (step 3) BEFORE scanning — otherwise malware re-infects from restore points. Reimaging (step 7) is the ONLY guaranteed removal method.

OBJ 2.2
Windows Security — BitLocker, EFS, UAC, Permissions

Encryption

BitLockerFull Disk Encryption (FDE). Encrypts entire volume including OS. Available on Pro/Enterprise (NOT Home). Protects data even if drive is physically removed. BitLocker To Go = removable USB drives
EFSEncrypting File System. NTFS-based per-file/folder encryption. Available on all editions except Home. Tied to user credentials — admin password reset = EFS files become inaccessible. Not FDE

UAC & Permissions

UACUser Account Control. Limits software access. Standard users can use network or change password. Admins can install apps or configure Remote Desktop. Secure Desktop = limits automated access
Run as AdminRight-click → Run as administrator. Uses admin rights even from standard account context. You don't get admin rights by just being in Administrators group

NTFS vs Share Permissions

NTFS PermissionsApply from BOTH local access AND network access. Inherited from parent object (unless moved to different volume). Explicit permissions override inherited deny
Share PermissionsApply ONLY when accessing over the network (network share). Do not apply to local access
Most restrictive setting wins (Deny beats Allow)
When both NTFS and Share permissions apply, the MORE restrictive of the two takes effect
InheritedPropagated from parent to child objects. Set permission once = applies everywhere underneath
ExplicitSet directly on the object. Overrides inherited deny permissions
KEY EXAM TRAP: Hidden shares (ending in $) are NOT a security feature — they're just hidden from browse lists. They're still accessible if you know the path.

Rooting (Android) / Jailbreaking (iOS): Gains unauthorized OS access. Install custom firmware. Circumvents security features, allows sideloading. Renders MDM useless. Company BYOD policies must address this.

Backup Types — Comparison
Backup TypeWhat It Backs UpBackup TimeRestore TimeWhat You Need to Restore
FullEverything — all selected dataHigh (longest)Low (fastest)Just the one full backup set
IncrementalFiles changed since the LAST BACKUP (full OR incremental)Low (smallest)High (slowest)Full backup + ALL incremental backups in sequence
DifferentialFiles changed since the LAST FULL backupModerate (grows over time)ModerateFull backup + LAST differential backup only (2 sets max)
Synthetic FullAll data — built from existing backups without running a new fullLow (efficient)Low (fast)Just the synthetic full — combines efficiency of incremental with convenience of full
🔴 Incremental restore: Need the FULL + every incremental since. If Tuesday's incremental is missing, restoration fails. Most complex restore.
🟡 Differential restore: Need only 2 sets: the last Full + the last Differential. Simpler restore but backup grows larger each day.
🟢 3-2-1 Rule: 3 copies of data | 2 different media types (local drive + NAS/tape) | 1 copy offsite (cloud or remote location)
GFS Rotation (Grandfather-Father-Son): Grandfather = monthly full backups | Father = weekly full backups (every Monday) | Son = daily incremental/differential (Mon–Fri). Twelve monthly, four/five weekly, thirty daily backups.
OBJ 4.2
Change Management Process

Change Management Process Steps

  • 1
    Complete the request form — document the change
  • 2
    Determine the purpose of the change — compelling reason required
  • 3
    Identify the scope — how many systems affected?
  • 4
    Schedule a date and time — maintenance window
  • 5
    Determine affected systems and impact — what breaks if this goes wrong?
  • 6
    Analyze risk — high, medium, or low. What's the risk of NOT changing?
  • 7
    Get approval from change control board
  • 8
    Get end-user acceptance after change is complete

Change Types

StandardLow risk. Pre-approved. Well-documented, happens all the time. Example: replacing a monitor on a user's desk
NormalMedium risk. Not urgent. Follows full change management process. Example: upgrading database engine or replacing a core switch
EmergencyHigh risk. Must be implemented quickly. Example: patch for a public-facing zero-day vulnerability. Still needs documentation after the fact

Key Concepts

Rollback PlanHow to revert the change if it fails. Always have one. Not always easy (backups are critical)
Sandbox TestingTest change in isolated environment first. No connection to production. Confirm rollback plan works here
Change FreezePeriod where no changes are allowed. Example: November 15 – January 5 (holiday freeze). No exceptions
Maintenance WindowScheduled time for changes. Often 2 AM Sunday. Minimizes user impact
OBJ 4.6
Incident Response — Chain of Custody & Order of Volatility

Chain of Custody

  • 1
    Identify the issue — Logs, in person, monitoring data
  • 2
    Report to proper channels — Don't delay. May include management or law enforcement
  • 3
    Collect evidence — Everyone who touches evidence is documented. Use hashes to prove integrity
  • 4
    Copy the drive (bit-for-bit) — Use hardware write-blocker to preserve data. Use software imaging tools on bootable device. Hash the image
  • 5
    Label and catalog everything — Seal, store, protect. Use digital signatures
  • 6
    Document findings — Summary, data acquisition details, findings analysis, conclusion

Order of Volatility (Most → Least)

Collect in this order — most volatile disappears fastest

Most VolatileCPU registers, CPU cache
↕Router table, ARP cache, process table, kernel statistics, RAM (memory)
↕Temporary file systems
↕Disk (HDD/SSD)
↕Remote logging and monitoring data
↕Physical configuration, network topology
Least VolatileArchival media (tapes, optical discs)

ESD, Safety & Environmental Procedures

ESD (Electrostatic Discharge)

You feel static at ~3,500VElectronic components damaged at just 100V or less
Anti-static wrist strapConnect wrist to metal chassis. Most reliable protection
Anti-static matWorkspace surface. Stand or sit on anti-static mat
Anti-static bagStore and transport components safely
Humidity >60%Reduces static buildup (not always practical)
Self-ground techniqueTouch exposed metal chassis AFTER unplugging power. Do NOT connect yourself to electrical ground!

Electrical Safety

Remove ALL power before workingHIGH VOLTAGE inside: PSUs, displays, laser printers — even when unplugged
Replace PSU entirelyNever repair internal components of a PSU
NEVER connect to electrical groundNot a way to prevent ESD — will electrocute you
Electrical fireUse CO2, FM-200, or dry chemicals. NEVER use water or foam on electrical fires

Environmental / MSDS

MSDS / SDSMaterial Safety Data Sheet — from OSHA (osha.gov). Covers batteries, toner, solvents, CRTs. Product info, hazards, first aid, fire-fighting, handling
BatteriesDispose at local hazardous waste facility. Do NOT throw in trash
TonerRecycle/reuse. Manufacturer return boxes. Some office supply stores give credit per cartridge returned
CRTs / DisplaysHigh voltage inside. Refer to MSDS. Do not just throw out

Room Environment

Temperature50–80°F / 10–27°C. Devices need constant cooling
Humidity~50% ideal. High = condensation risk. Low = static discharge risk
VentilationProper airflow. Computers generate significant heat. Don't put in enclosed closets
UPS TypesStandby (basic), Line-interactive (common), On-line (full protection). Features: auto-shutdown, battery backup, surge suppression
Surge SuppressorJoule rating: look for >600J. UL 1449 voltage let-through: lower is better (330V ideal)

OBJ 2.10
SOHO Network Security — Best Practices
ControlDetails
Change Default PasswordsAll APs/routers have defaults. Easily found at routerpasswords.com. Change immediately. Right credentials = full admin access
Firmware UpdatesManufacturer provides bug fixes, features, security patches. Install latest. Closed architecture — only manufacturer updates
IP FilteringAllow list (only approved pass) or Deny list (blocked list, rest allowed). Filter by IP, domain, URL, or content category
Disable UPnPUniversal Plug and Play — allows apps to open inbound ports automatically. Security risk. Disable unless specifically needed
SSID ManagementChange default SSID (don't use LINKSYS/NETGEAR). Disabling SSID broadcast = security through obscurity — SSID still detectable via wireless analysis
Disable Guest Network (or restrict)Often enabled by default. Can be used for IoT or lab networks but NEVER without WPA2/3 security
Disable Unused PortsConference rooms, break rooms. NAC (802.1X) = can't communicate until authenticated
Port ForwardingMaps external IP:port to internal IP:port. Destination NAT / Static NAT. For servers accessible from internet. Does not expire
Screened Subnet (DMZ)Previously called DMZ. Layer between internet and internal network. Public access to public resources. Adds security layer
Content FilteringURL filtering, website category, corporate control of outbound/inbound content, anti-virus/anti-malware integration

Wireless Channel & Security Config

Open SystemNo authentication password required
WPA/2/3-Personal (PSK)Pre-shared key. Everyone uses same 256-bit key passphrase
WPA/2/3-Enterprise (802.1X)Each user authenticates individually via RADIUS/LDAP authentication server
Secure Management Access: Management access to SOHO router should be tightly controlled. Use complex password + MFA if available. Limit management to local logins only. Disable remote management access unless absolutely needed.
Physical Placement: AP location matters — above ceiling tiles is common but causes power cycling problems. Location affects coverage. For secure rooms: restrict physical access to switches, routers, servers.
